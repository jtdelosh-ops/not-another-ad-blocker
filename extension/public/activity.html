This session-only log keeps the newest 300 matches across tabs and removes a tab's records when it closes. It includes earlier pages visited in the same tab and is not a complete page history.

Request URLs omit credentials, query strings, and fragments. Paths can still contain sensitive information. Entries identify the compiled rule set; they do not identify an exact original filter line. An exception match records an allowance by NAAB; it does not prove that the request loaded.

Rule details and tab site reflect the configuration observed when an event arrives; matches around rule changes or navigation may lack exact historical attribution.

Refresh updates this view. Clear all recent activity removes records for every tab without resetting the browser's page counter. Nothing in this log is sent to a server.
